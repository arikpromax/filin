# «ФІЛІН» — Кобеляки

Два сайти під одним доменом. Без збірки й залежностей — звичайні HTML-файли,
відкриваються подвійним кліком.

| Файл | Що це |
|---|---|
| `index.html` | Мотель і сауна: номери, ціни, галерея, бронювання |
| `cafe/index.html` | Меню кухні (QR-меню) з вибором страв і замовленням |
| `photos/` | Фото мотелю — інструкція з іменами файлів усередині |
| `cafe/photos/` | Фото страв — інструкція з іменами файлів усередині |

## Як додати фото

Просто покладіть файли у відповідну папку з іменами з інструкції
(`ЯК-ДОДАТИ-ФОТО.txt` і `ЯК-ДОДАТИ-ФОТО-СТРАВ.txt`). Сайт підхопить їх сам,
нічого правити не треба. Можна кілька фото на один номер або страву —
`room-single-1.jpg`, `room-single-2.jpg` тощо.

## Як змінити меню

Усі страви й ціни — в одному місці, у змінній `MENU` всередині
`cafe/index.html`. Формат і приклади описані коментарем угорі того ж файлу.

## QR-коди для столиків

Посилання для QR-коду містить номер столика:

```
https://ваш-домен/cafe/index.html?t=1
https://ваш-домен/cafe/index.html?t=2
```

Тоді меню саме підставить номер столика в замовлення.

## Адмінка

Сайт підключений до платформи: тексти, номери, меню кухні, фото й графік
беруться з бази, а власник редагує їх в адмінці. Якщо база недоступна —
сторінка показує вбудований вміст і нічого не ламається.

**Щоб увімкнути:** один раз виконайте `platform/db/migration-filin.sql`
у SQL Editor проєкту platform. Він реєструє сайт №4 і наповнює адмінку
поточним вмістом. Повторний запуск безпечний — те, що власник уже
відредагував, не перезаписується.

Розділи адмінки повторюють блоки сайту зверху вниз: «1. Головний екран»,
«2. Про нас», «3. Номери» і так далі до «11. Кухня — про кухню».

### Каталог кімнат

У блоці «Номери» гість бачить типи (одномісний, двомісний, сімейний).
Натиснув на тип або на «Дивитись усі номери» — відкривається каталог
конкретних кімнат: «Одномісний №1», «Одномісний №2» і так далі, з фото,
ціною та фільтром за кількістю осіб. Уже там обирають кімнату й бронюють —
її номер сам підставляється в заявку.

Скільки кімнат кожного типу — задає поле **«Номери кімнат через кому»**
в картці типу: напишете `1, 2, 3, 4` — у каталозі буде чотири одномісні.
Порожнє поле — у каталозі просто один запис без номера.
Поле з’являється після `platform/db/migration-filin-v6.sql`.

Що редагується: усі заголовки й тексти, обидва телефони, години роботи
(вони ж керують статусом «Відчинено» і зворотним відліком), номери з цінами
й фото, смуга переваг, позначки сауни, стрічка фото, графік у контактах,
розділи меню, страви з цінами й фото, чотири факти про кухню, посилання
на Instagram і карту.

## Що ще треба замінити на справжнє

- ціни номерів (зараз від 600 / 750 / 950 ₴);
- **усі страви та ціни в меню** — зараз це заготовка, а не реальне меню кафе;
- точна адреса;
- фото.
