# «ФІЛІН» — Кобеляки

Два сайти під одним доменом. Без збірки й залежностей — звичайні HTML-файли,
відкриваються подвійним кліком.

| Файл | Що це |
|---|---|
| `index.html` | Мотель і сауна: номери, ціни, галерея, бронювання |
| `cafe/index.html` | Меню кухні (QR-меню) з вибором страв і замовленням |
| `photos/` | Фото мотелю — інструкція з іменами файлів усередині |
| `cafe/photos/` | Фото страв — інструкція з іменами файлів усередині |

## Як додати фото

Просто покладіть файли у відповідну папку з іменами з інструкції
(`ЯК-ДОДАТИ-ФОТО.txt` і `ЯК-ДОДАТИ-ФОТО-СТРАВ.txt`). Сайт підхопить їх сам,
нічого правити не треба. Можна кілька фото на один номер або страву —
`room-single-1.jpg`, `room-single-2.jpg` тощо.

## Як змінити меню

Усі страви й ціни — в одному місці, у змінній `MENU` всередині
`cafe/index.html`. Формат і приклади описані коментарем угорі того ж файлу.

## QR-коди для столиків

Посилання для QR-коду містить номер столика:

```
https://ваш-домен/cafe/index.html?t=1
https://ваш-домен/cafe/index.html?t=2
```

Тоді меню саме підставить номер столика в замовлення.

## Що ще треба замінити на справжнє

- ціни номерів (зараз від 600 / 750 / 950 ₴);
- **усі страви та ціни в меню** — зараз це заготовка, а не реальне меню кафе;
- точна адреса;
- фото.
